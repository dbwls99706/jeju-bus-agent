# 공개 체험판 검증

2026-11-12, Vercel Hobby에 `web-demo` 디렉터리로 배포했습니다.

- 공개 주소: https://busyeoul-demo.vercel.app/
- 비로그인 HTTP GET 200, catalog 840행·합성 자료·AI 비활성 확인.
- 공개 API에서 계획→승인 분석 성공, 다른 Origin의 POST 403 확인.
- 실제 Chromium에서 합성 시간대 분석의 계획 확인→계산→7행 결과 확인.
- 실제 파일 선택으로 합성 CSV 840행의 로컬 합계 36,232 확인, 지우기 동작 확인.
- 로컬 CSV 코드는 File.arrayBuffer/TextDecoder/정수 집계만 사용합니다. fetch, XHR, WebSocket, sendBeacon, 스토리지 호출이 없고 서버에는 파일 업로드 경로가 없습니다. 단위검사로 이 제한을 확인했습니다. 모든 종류의 브라우저 확장 프로그램이나 플랫폼 요청을 패킷 캡처한 감사는 아닙니다.
- 공개 페이지는 합성 예제와 실제 사용자가 선택한 파일의 로컬 분석을 구분하고, 양쪽 모두 AI 미사용을 표시합니다.
- 15개 Flask 검사와 별도 Node CSV 파서·안전성 검사 통과.

이 체험판은 제출본의 Qwen AI 실행이나 실제 데이터 성능을 입증하지 않습니다. 실제 데이터·모델·비밀키는 공개 서버에 올리지 않았습니다. Hobby 한도 초과 시 가용성이 제한될 수 있으며 상시 운영을 보장하지 않습니다.
