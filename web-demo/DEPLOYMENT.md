# 공개 체험판 검증

2026-11-12, Vercel Hobby에 `web-demo` 디렉터리로 배포했습니다.

- 공개 주소: https://busyeoul-demo.vercel.app/
- 비로그인 HTTP GET 200, catalog 840행·합성 자료·AI 비활성 확인.
- 공개 API에서 계획→승인 분석 성공, 다른 Origin의 POST 403 확인.
- 실제 Chromium에서 합성 시간대 분석의 계획 확인→계산→7행 결과 확인.
- 실제 파일 선택으로 합성 CSV 840행의 로컬 합계 36,232 확인, 지우기 동작 확인.
- 로컬 CSV 코드는 File.arrayBuffer/TextDecoder/정수 집계만 사용합니다. fetch, XHR, WebSocket, sendBeacon, 스토리지 호출이 없고 서버에는 파일 업로드 경로가 없습니다. 단위검사로 이 제한을 확인했습니다. 모든 종류의 브라우저 확장 프로그램이나 플랫폼 요청을 패킷 캡처한 감사는 아닙니다.
- 공개 페이지는 합성 예제와 실제 사용자가 선택한 파일의 로컬 분석을 구분하고, 양쪽 모두 AI 미사용을 표시합니다.
- 15개 Flask 검사와 별도 Node CSV 파서·안전성 검사 통과.

이 체험판은 제출본의 Qwen AI 실행이나 실제 데이터 성능을 입증하지 않습니다. 실제 데이터·모델·비밀키는 공개 서버에 올리지 않았습니다. Hobby 한도 초과 시 가용성이 제한될 수 있으며 상시 운영을 보장하지 않습니다.

추가 화면 확인: CSS 뷰포트 509px에서 페이지 전체 가로 넘침 없음(body/root494px). 실제 휴대전화 장치 검증은 아닙니다.

## 실제 자료 모드 전환

실제 데이터 웹 활용 및 공개 GitHub 재배포에 대한 사용자 승인 후, 압축 CSV를 포함하고 기본 `DATA_MODE=real`로 전환했습니다. 출처와 공식 2차 메타의 CC0 표기·원포털 미확인 한계는 `data/README.md`와 화면 경고에 표시합니다. 기존 위 합성 모드 검증 기록은 이전 배포의 기록입니다.

- 실제 37,057행과 원본 SHA-256 일치 검증, 계획 확인 후 집계.
- 웹은 규칙 기반이며 `ai_enabled=false`. OpenAI 준비 모듈은 웹 요청 경로에 연결하지 않았고 실제 유료 호출 0회.
- 로컬 ZIP/PDF는 기존 로컬 앱 및 Qwen 계획 분류 구성을 설명합니다. 공개 웹은 별도 Flask 어댑터, AI 미실행, 원본 자료 공개 범위가 추가된 버전으로 동일 실행환경이 아닙니다. 제출 ZIP/PDF를 이번 배포로 변경하지 않았습니다.
- 40개 단위·회귀 검사 통과. AI 관련 검사는 모두 mock이며 실제 모델 성능 검증이 아닙니다.

공개 배포 후 실제 Chromium에서 37,057행·672개 날짜와 출처 경고를 확인했습니다. 2024년 1~2월 일반 유형 계획→명시 승인→집계 결과 합계 431,590/414,442, 일평균 13,922.26/14,291.1 및 요일 구성 차이에 따른 단순 증감 보류를 확인했습니다. 공개 GitHub의 gzip을 다시 내려받아 풀었을 때 원본 SHA-256과 일치했습니다.
