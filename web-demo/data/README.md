# 공개 데이터 출처

`bus.csv.gz`는 사용자가 제공한 `일별시간대별버스승차인원수현황.csv`를 내용 변경 없이 gzip 압축한 자료입니다. 압축을 풀면 CSV로 사용할 수 있습니다.

- 제공기관: 제주빅데이터센터
- 원본 안내: https://www.jejudatahub.net/data/view/data/512
- 교육부·KERIS 공식 2차 메타: https://data.edmgr.kr/dataView.do?id=jejudatahub-net-512
- 이용조건 근거: 공식 2차 메타의 동일 데이터명·파일명에 `cc-zero` 표기
- CC0 안내: https://creativecommons.org/publicdomain/zero/1.0/deed.ko
- 주의: 원본 포털 접속 제한으로 현행 이용조건과 사용자 파일의 원포털 버전 동일성을 대조하지 못했습니다. 공식 2차 메타를 근거로 사용합니다. 기관의 후원·보증을 뜻하지 않습니다.
- CSV SHA-256: `acecf3fa511c68def3b68c34c29610dbda1101070f38e4be856cdcb123a4a529`
- 37,057행, 672개 날짜, 2023-12-25~2025-10-26
- 과거 승차 집계이며 고유 인원·실시간 혼잡도·배차·노선 또는 지역별 안내가 아닙니다. 미기록 조합은 0이 아닙니다.

웹은 이 파일을 해시 검증한 뒤 집계합니다. 잘못된 파일이면 합성 자료로 몰래 대체하지 않습니다. 웹의 원본 파일 다운로드 경로는 제공하지 않지만 **공개 GitHub의 이 파일은 누구나 다운로드할 수 있습니다.**

`synthetic.csv`는 테스트 전용 합성 데이터입니다. `DATA_MODE=synthetic`을 명시해야 사용됩니다. 기본 웹 모드는 `real`입니다. 어느 모드에서도 현재 AI API 호출은 활성화하지 않았습니다.
