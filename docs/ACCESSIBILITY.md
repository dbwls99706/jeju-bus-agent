# 버스여울 화면 접근성 개선

## 참조 기준

W3C의 공개 웹 접근성 표준 WCAG 2.2 Quick Reference를 참조했습니다.
https://www.w3.org/WAI/WCAG22/quickref/

- 1.4.3 대비: 일반 글자 4.5:1, 큰 글자 3:1 기준.
- 1.4.4 글자 확대: 200% 확대 시 정보와 기능 유지.
- 1.4.10 리플로: 320 CSS px 폭에서 본문을 가로 스크롤 없이 읽기. 데이터 표처럼 2차원 배치가 필요한 영역은 별도 스크롤 가능.
- 2.4.7 포커스 표시: 키보드로 현재 조작 위치를 볼 수 있어야 함.
- 2.5.8 최소 목표 크기: 24×24 CSS px 및 예외 조건. 이 앱은 주요 조작에 더 넉넉한 48 px 높이를 목표로 합니다.
- 3.3.2 레이블/설명: 입력 목적과 다음 동작을 명확히 안내.

WCAG는 UI 라이브러리가 아닌 공개 표준입니다. 특정 오픈소스 컴포넌트를 도입한 것처럼 주장하지 않습니다. 브라우저의 기본 버튼·입력·details/summary 요소를 활용합니다.

## 적용 원칙

기본 18 px 본문, 17 px 보조 설명, 48 px 이상 주요 조작 높이, 쉬운 동작명과 단계별 계획 확인을 적용했습니다. 그래프와 표의 가로 스크롤은 해당 영역 안에 한정하고 전체 화면을 밀어내지 않도록 최소 폭을 조정했습니다. 원기간과 요일 표준화는 서로 다른 결과임을 유지하며, 미기록을 0으로 보지 않는다는 설명과 혼잡도·노선 분석이 아니라는 한계는 숨기지 않습니다. 긴 계산 근거는 펼쳐 보는 방식으로 정리하되 원자료와 저장 결과는 유지합니다.

## 검증의 한계

선별된 브라우저·코드 검사는 접근성 인증이나 WCAG 전체 적합성 심사가 아닙니다. 실제 어르신 참여 사용성 시험, 스크린리더 전체 흐름 및 다양한 보조기술 조합은 아직 검증하지 않았습니다. 최종 수행 범위는 research의 접근성 QA 기록과 docs/VALIDATION.md를 확인하세요.

고령 사용자 관련 W3C 안내: https://www.w3.org/WAI/older-users/
18 px 본문·48 px 주요 버튼은 이 앱의 편의 설계 목표이며 WCAG의 필수 글자 크기나 인증 기준이라고 주장하지 않습니다.
