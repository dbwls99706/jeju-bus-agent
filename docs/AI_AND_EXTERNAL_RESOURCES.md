# AI 활용·역할·외부 자원 고지

공식 규칙 확인 위치: https://daker.ai/public/hackathons/jeju-ai-bigdata-agent-challenge
확인일: 2026-11-12. 최종 제출 시 AI 모델·활용 범위·외부 API/서비스·데이터·오픈소스·외부 코드 명시 요구에 따라 구분합니다.

## 역할과 개발 지원

- 참가 요청자는 대회 참여 의사, 자료 제공, 개선 방향과 검토 요청을 전달했습니다. 참가자의 직접 코딩이나 현장 검증 수행을 추가로 주장하지 않습니다.
- **ChatGPT 지원을 받아 코드 구현·수정, 테스트 작성·실행, 독립 검토, 통계 검산, 문서·제출자료 작성 및 브라우저 점검을 진행했습니다.** 생성 결과를 그대로 정답으로 간주하지 않고 단위검사·독립 SQLite 계산·실제 브라우저 실행으로 확인한 범위와 남은 제한을 구분했습니다.
- 개발 지원에 사용된 ChatGPT의 정확한 내부 모델 버전은 이 자료에서 확인하지 못했으므로 임의로 기재하지 않습니다. 제출물의 모든 부분을 참가자가 직접 작성했다는 주장은 하지 않습니다. 최종 제출 여부와 제출 내용 확인은 참가자의 판단 대상입니다.

## 로컬 제출 ZIP의 실행 중 AI와 고정 계산 도구

- 로컬 모델: **Qwen/Qwen2.5-1.5B-Instruct**, 고정 리비전 `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`, Apache-2.0.
- 활용: 제한된 시간·요일·월·유형 분석 도구 분류. 프롬프트는 `planner.py`에 포함합니다. 명시 조건과 충돌하면 규칙으로 교정하고 화면에 실제 모드를 표시합니다.
- 모델이 임의 코드·SQL을 생성해 실행하지 않습니다. 조건 해석·집계·요일 표준화·숫자 주장 검증은 고정된 Python 도구입니다. 주장 판정은 AI의 자유문장 진실 판정이 아닙니다.
- 실행 중 외부 AI API, API 키 또는 유료 AI 서비스 호출은 없습니다. 최초 모델 설치 때 Hugging Face에서 고정 모델을 다운로드합니다. 의존성 설치는 공식 PyPI 및 PyTorch CPU 패키지 저장소를 사용합니다.
- 앱의 CSV와 사용자 질문은 로컬 프로세스에서 처리됩니다. 이 설명은 앱 실행 경로에 관한 것이며, 개발 단계에서 참가자가 ChatGPT에 자료를 제공한 사실과 구분합니다.

- 원본 연결: https://www.jejudatahub.net/data/view/data/512
- 공식2차 메타데이터: https://data.edmgr.kr/dataView.do?id=jejudatahub-net-512

- 날씨·노선·정류장·외부 인구 자료는 결합하지 않았습니다. 내부 검토용 대회 데이터목록은 제출 ZIP에 포함하지 않았습니다. 테스트용 합성 fixture는 실제 관측 자료로 제시하지 않습니다.

앱 주요 소스는 ChatGPT 지원으로 작성·수정한 코드이며 외부 라이브러리의 기능을 위 용도로 사용했습니다. 모델·라이브러리 배포물의 소유권이나 라이선스를 앱 자체 권리로 주장하지 않습니다. 직접 의존성 버전은 `requirements-ai.txt`와 README 설치 명령, 실제 설치 환경의 의존성 메타데이터는 `research/ai-package-inventory.json`을 참조하세요. 전이 의존성은 설치 도구가 해결하며 각 배포물의 라이선스가 적용됩니다. 모델·Python·npm 라이브러리 전체를 제출 ZIP에 복제하지 않았습니다.

개발·검증에는 ChatGPT의 로컬 실행 환경과 브라우저 도구를 사용했습니다. 이 고지는 Windows/센터 PC·인쇄·모델 최초 전체 다운로드를 실제로 검증했다는 의미가 아닙니다.

화면 개선은 W3C WCAG 2.2 및 고령 사용자 안내를 설계 참고로 사용했습니다. 해당 문서는 공개 표준/가이드이며 앱에 새로운 UI 라이브러리를 설치한 것은 아닙니다. 앱 아이콘·썸네일은 프로젝트에서 작성한 SVG 도형입니다. 상세 기준과 미검증 범위는 `docs/ACCESSIBILITY.md`를 참조하세요.

후속 시각 디자인은 Carbon Design System의 간격 체계와 GOV.UK Design System의 명확한 버튼·주 행동 구분 원칙을 참고했습니다. 외부 코드를 추가 실행하거나 해당 UI 패키지를 설치하지 않았습니다. 공식 참고 URL과 적용 구분은 `docs/DESIGN_REFERENCES.md`에 명시합니다.


## 별도 공개 웹 버전과의 차이

- 로컬 제출 ZIP은 위 Qwen 선택 분류이며 외부 API 키가 필요하지 않습니다.
- 별도 웹 버전은 사용자가 동의하고 별도 AI 버튼을 눌렀을 때 OpenAI `gpt-6-luna`로 질문의 도구 분류를 수행합니다. 원본 CSV와 집계 결과는 해당 AI 요청에 보내지 않고 고정 Python 도구가 계산합니다. 질문에 개인정보·민감정보를 적지 않도록 안내합니다.
- 웹 담당의 실제 검증에서 2회 모델 분류가 성공했고 Python7시간대 집계를 확인했습니다. 두 번째 호출은 입력124·출력14토큰이 관측됐습니다. 이는 광범위한 모델 성능 평가나 로컬 Qwen 평가 결과를 대체하지 않습니다.
- 웹은 Vercel 서비스와 Upstash Redis의 요청량 관리에 의존합니다. 설정상 총20,000/일1,000/분10회 제한이며, 외부 API 비용이 발생할 수 있습니다. 이 횟수 제한은 결제 총액을 보장하는 한도가 아닙니다. API 키는 공개 산출물에 포함하지 않습니다.
- 공개 웹 운영 변경·할당량 소진·서비스 장애와 별개로 로컬 ZIP은 지정 데이터를 이용해 재현합니다. 이 ZIP에 웹 API 키나 Redis 자격증명, 모델 가중치를 동봉하지 않습니다.

소개 사진은 Bernard Gagnon의2022년 제주돌문화공원 CC0 자료를 Wikimedia Commons 공식960px 썸네일로 동봉했습니다. 분석용 입력 데이터가 아니라 실제 장소의 소개 이미지이며, 무장애 인증이나 현재 접근성을 검증한 것이 아닙니다. 출처·허락·파일 설명은 `docs/PHOTO_CREDITS.md`에 있습니다. Astryx는 MIT 공개 시스템 및 draft 설계문서를 참고했으며 패키지/CLI를 실행하거나 컴포넌트 코드를 복제하지 않았습니다.

결과 시각화는 D3 선형 척도, Vega 접근 가능한 설명, W3C 복잡한 이미지의 텍스트 대안, Carbon 차트 구성 지침을 참고했습니다(`docs/RESULT_VISUALIZATION.md`). 시각화 패키지를 앱에 설치하지 않았으며 원자료 계산·요일 표준화·주장 판정 도구는 그대로 유지합니다.
