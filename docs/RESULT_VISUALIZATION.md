# 결과를 읽는 시각화 원칙

## 검토한 공개 자료

- D3 선형 척도: https://d3js.org/d3-scale/linear
  수치 차이의 비례 관계를 보존하는 선형 표현을 참고합니다.
- Vega 시각화 설명/ARIA: https://vega.github.io/vega/docs/config/
  차트의 의미를 접근 가능한 설명으로 제공하는 원칙을 참고합니다.
- W3C 복잡한 이미지: https://www.w3.org/WAI/tutorials/images/complex/
  그래프를 식별하는 짧은 설명과 핵심 정보의 텍스트/표 대안을 함께 제공합니다.
- Carbon 차트 구성: https://www.carbondesignsystem.com/building-blocks/data-visualization/chart-anatomy
  목적을 알리는 제목·직접 값 표시·단위·축으로 해석 맥락을 전달하고 과밀을 피합니다.

D3·Vega는 검증된 공개 시각화 프로젝트의 문서 참고입니다. 현재 앱에 해당 패키지를 설치하거나 외부 라이브러리 코드를 복제한 것은 아닙니다. 기본 앱은 인터넷 없이 작동하는 기존 직접 구현을 사용하며, 주로 단순 범주·기간 비교를 표시합니다.

## 통계 해석의 경계

- 핵심 결론 → 같은 단위의 수치 비교 → 직접 값이 붙은 그래프 → 별도 요일 표준화 카드(해당 시) → 다음 행동 순서로 읽을 수 있어야 합니다.
- 막대는0을 기준으로 길이를 표시합니다. 값이0인 기록과 기록이 없는 null은 다르게 표시합니다. 미관측에는0 막대를 만들지 않습니다.
- 모든 해당 범주를 보존하며, 임의로 일부만 골라 결론을 부풀리지 않습니다.
- 합계·일평균·요일표준화 일평균은 서로 다른 지표입니다. 서로 다른 단위를 한 축에서 비교하지 않습니다.
- 비교 보류 이유와 기록 누락은 숨기지 않습니다. 원지표 직접 비교가 보류돼도 승인된 별도 요일 표준화의 제한된 결과는 명확히 구분할 수 있습니다.
- 색상만으로 증가·감소·보류를 구분하지 않습니다. 숫자·문구·단위가 함께 있어야 합니다.
- 원본 표·근거·내보내기를 보존하며, 시각적 요약은 추가 분석이나 인과 추론을 뜻하지 않습니다.

표준화 카드는 원지표 차트 직후에 놓아 이미 계산한 별도 결과를 놓치지 않도록 합니다. 원지표 비교 보류와 계절·공휴일 미통제 경고는 그대로 유지하며, 카드의 이동만으로 새 계산을 실행하지 않습니다.
